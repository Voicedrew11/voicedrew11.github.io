# My Review of various Bible Translations

When I first became a Christian, Bible translations became a facisination for me. I would go out to flea markets and second hand stores to purchase volumes 

## King James Version
To be entirely honest, I do not understand the hype around the KJV. It's the sort of thing I imaging you would have to grow up using in order to use effectivly. It is written in Elizibethan English, which is lost on most uninformed contemporary worshipers. I find it's use in the protestant context to be confusing, since it is an afront to being allowed to worship in ones own tounge

## New Living Translation
The NLT was the version I actually started with. The language is simple, while still not plain, and more on the dynamic side of things (although still well within tolerance). 

The main appeal of this translation is that basically anybody that can read english can read and understand it. For instance, when I read John for the first time, I had at that point not read a book for at least 3 years.
